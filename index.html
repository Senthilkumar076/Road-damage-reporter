Common questions

Do I need to log in?

No. Anyone can report a road problem without creating an account.

Is my location safe?

Your location is shared only when you press the button, and only the damaged road location is saved.

What does "I saw this too" mean?

It shows many people are facing the same problem, so it can be fixed sooner.

Who changes the status to Fixed?

Only the admin can change the status after the work is done.
